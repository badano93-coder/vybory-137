# Электоральная карта округа №137

Интерактивная карта и разбор итогов выборов в Государственную Думу 20 сентября 2026 года
по Новосибирскому одномандатному избирательному округу №137.

**Открыть карту → https://badano93-coder.github.io/vybory-137/**

Данные — протокольная таблица МОСведений: 497 участковых комиссий плюс дистанционное
электронное голосование. Сумма по всем участкам сходится с итогом округа до одного голоса
по каждому из восьми кандидатов.

## Что внутри

| Раздел | Содержание |
|---|---|
| **Карта** | 497 участков с границами, восемь переключаемых слоёв, врезка по Новосибирску, карточка участка по клику |
| **Выводы** | Текстовый разбор: откуда взялось отставание, что его создало и что из этого следует |
| **Графики** | Вклад территорий, децили по явке, диаграмма рассеяния, корреляции с соперниками, аномалии |
| **Участки** | Таблица всех участков с поиском, фильтрами, сортировкой и выгрузкой в CSV |

Ссылка может открывать сразу нужный вид: `#rp` — выводы, `#an` — графики, `#tb` — таблица,
`#city` — городская часть, `#pl_nl` и другие имена слоёв — конкретный слой карты,
`#dark` — тёмная тема. Части складываются через запятую: `#city,pl_nl`.

Страница подходит для телефона: карта приближается щипком двумя пальцами и кнопками
на самой карте, слои переключаются лентой, карточка участка открывается шторкой снизу.

## Главные результаты

1. **Электронное голосование дало 41% всего отставания** — 13 749 голосов из 33 336.
   Явка в ДЭГ 90,3% против 42,6% по округу.
2. **Городская часть выиграна:** 27,76% против 26,84% у кандидата «Единой России».
   Всего выиграно 106 участков из 497.
3. **Явка — главный предсказатель результата.** Корреляция явки с результатом победителя
   +0,78. Перелом проходит около 34%: ниже неё лидирует КПРФ, выше — «Единая Россия»,
   и разрыв растёт до 44,7 пункта в группе участков с явкой 72–100%.
4. **Малые партии не отнимали протестные голоса.** Корреляция результата КПРФ с «Новыми
   людьми» +0,16, с «Яблоком» +0,33 — они росли на тех же участках. В противофазе
   оказались «Родина» (−0,56) и Партия пенсионеров (−0,51).
5. **Аномалии:** 30 участков с явкой от 80% и 137 участков, где доля голосования вне
   помещения превысила 20% при среднем по округу 10,9%.

## Данные и их качество

- **Результаты — точные,** из протокольной таблицы; контрольные суммы сходятся до голоса.
- **Адреса городских участков — официальные:** 147 из 150 разобраны из перечня
  избирательных участков мэрии Новосибирска в редакции от 08.07.2026.
- **Координаты проверены дважды:** геокодирование адресов сверено с открытым датасетом
  координат участков 2021 года (медиана расхождения 14 м, 95% точек ближе 200 м) и
  дополнительно — на попадание точки внутрь границ своего района (490 из 491).
- **Границы участков на карте — приближение.** Настоящие границы УИК публикуются только
  текстом, перечнем улиц и домов; геоданных по ним в открытом доступе не существует.
  Закрашенные области — полигоны Вороного внутри района. Для городских участков в карточке
  приведено официальное текстовое описание границ.
- **Семь участков без установленного места** — закрытые учреждения и участки временного
  пребывания, адреса которых не публикуются. В расчётах они участвуют полностью.

## Источники

- Результаты — МОСведения по округу №137
- Адреса и текстовые границы городских участков — постановление мэрии Новосибирска № 13130
  в действующей редакции, [nskpravo.info](https://nskpravo.info)

- Административные границы — [OpenStreetMap](https://www.openstreetmap.org) через Overpass API

Страница работает без сервера и без сборки: обычный HTML, данные лежат рядом,
внешних зависимостей нет кроме шрифтов Google Fonts.
